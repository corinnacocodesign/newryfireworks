# Newry Fireworks — GitHub Pages version

Upload the contents of this folder to the root of your GitHub repository.

Then open **Settings → Pages** and choose:

- Source: **Deploy from a branch**
- Branch: **main**
- Folder: **/ (root)**

The site requires no installation or build command.

## Updating shop prices

Open `products.js` on GitHub and edit the product names, descriptions and prices. Commit the change and GitHub Pages will update automatically.

## Pages included

- `index.html` — homepage and shop addresses
- `shop.html` — searchable retail price list
- `weddings.html` — packages and wedding video
- `safety.html` — firework safety code
- `licence.html` — official Category F2 application link
